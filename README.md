# Junk Shop Inventory & Sales Tracker\n\nA seller-side one-page app. Add stock and prices, then record sales to customers. Payments are received by the shop; sold quantity is deducted from available stock.\n\n## FR-01\nThe junk shop owner can record a sale by selecting an inventory item, entering quantity sold and date. The system calculates payment received and updates remaining stock.\n\n## Features\n- Separate Inventory and Sales/Payments views\n- Item name, starting stock and selling price per kg\n- Sales entries and payment calculations\n- Remaining stock automatically updated based on sales\n- Overselling prevented\n- localStorage persistence\n\nOpen `index.html` in a browser. Use made-up data only. No server or database required.\n
