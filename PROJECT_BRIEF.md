# Project Brief\n\n**Pitch:** A small web app for a junk shop seller to manage stock and record sales to customers.\n\n**Problem:** Manual records can make it difficult to track stock, quantities sold and payments received.\n\n**User:** Junk shop owner/seller.\n\n**FR-01:** The owner can record a sale by selecting an inventory item, entering quantity sold and date. The app calculates payment and deducts quantity sold from inventory.\n\n**Architecture:** Single HTML page with CSS and JavaScript; localStorage. No login, server or database.\n
